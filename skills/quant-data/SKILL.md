# 数据获取与治理

数据是唯一事实来源。本技能判定"这份数据能不能用"，并给出取数的确定命令。

## 1. 取数通道与降级顺序

**A股/ETF/指数**（按序尝试，失败再降级）：
1. MCP 通道（首选，已封装）：`mcp__aiquant__q_klines`、`mcp__aiquant__q_quote`。
2. 本地 `aiquant` 环境库：`akshare 1.19.1`、`efinance 0.5.9`、`baostock 0.9.4`、`mootdx 0.11.7`、`tushare 1.4.29`（tushare 需 token，见 §6）。

**港美股**：`akshare` 对应接口，或 `yfinance 1.7.0`。
**加密**：`mcp__aiquant__q_crypto_klines`，或 `ccxt 4.5.85`。

调用前自检通道可达：

```powershell
& "C:\Users\33096\.conda\envs\aiquant\python.exe" -c "import akshare,baostock,efinance,ccxt,yfinance;print('ok')"
```

MCP 侧用 `mcp__aiquant__q_env`，DSH 侧用 `aiquant_env`。

## 2. symbol 规范化规则

统一成"内部规范码"，写进缓存文件名与所有结论里，避免同一标的出现多种写法：

| 市场 | 规范格式 | 示例 | 常见错误写法 |
|---|---|---|---|
| 上交所 | `SH` + 6 位 | `SH600519` | `600519.SH`、`sh600519` |
| 深交所 | `SZ` + 6 位 | `SZ000001` | `000001.SZ` |
| 北交所 | `BJ` + 6 位 | `BJ430047` | `430047` |
| 港股 | `HK` + 5 位 | `HK00700` | `0700.HK` |
| 美股 | `US:` + 代码 | `US:AAPL` | `AAPL.US` |
| 加密 | `交易所:` + 交易对 | `BINANCE:BTCUSDT` | `BTC-USDT` |

规则：
1. 先判市场再补前缀：6 位数字以 `6`/`9` 开头→SH，`0`/`3` 开头→SZ，`4`/`8` 开头→BJ。
2. 中文名（"茅台"）先解析成规范码并回读校验；解析不出就报"未识别"，禁止猜。
3. 指数单独标记（如 `SH000300`），不与个股混入同一池子。
4. 一个标的全链路只用一种写法：缓存文件名、params.yaml、回测报告三处必须完全一致。

## 3. 复权与停牌处理

**复权**：默认取**前复权**（`qfq`）用于信号与回测；需要与历史价格对齐做展示时才用后复权（`hfq`）。禁止混用：同一因子序列里同时出现不复权与前复权 = 数据无效。基准日必须写进结论（前复权随基准日变化，不同日取数结果不同）。

**停牌**：
1. 停牌期间保留日期行、成交量为 0，价格沿用前收。删行会让持有天数与换手率失真。
2. 停牌股不得作为可成交标的：回测里该日按不可成交处理（见 `quant-backtest`）。
3. 长期停牌（>20 交易日）与退市股在选股池中剔除，并记录剔除数量。

**涨跌停与 ST**：原始行情需额外标注当日是否涨停/跌停，供回测判断不可成交。

## 4. 时区与交易日历

- A股：`Asia/Shanghai`，连续竞价 09:30–11:30、13:00–15:00。日线数据的日期字段按**交易日**，不是自然日。
- 港股：`Asia/Hong_Kong`，09:30–12:00、13:00–16:00。
- 美股：`America/New_York`，注意夏令时切换。
- 加密：`UTC`，7×24 无休市，不存在停牌概念。
- 任何"最近 N 天"必须先映射到交易日：N 个自然日 ≠ N 个交易日。跨市场比较统一转 UTC 再对齐。
- 存储约定：文件名带交易日与市场，如 `SH600519_1d_qfq_20261009.csv`；时间戳一律 ISO 8601 带时区。

## 5. 缓存目录与命名

缓存根固定 `D:\量化\data\cache`。分层：

```
D:\量化\data\cache\<市场>\<规范码>\<周期>_<复权>_<起>_<止>.csv
```

- 取数成功后先写缓存再计算；同一参数命中缓存直接复用。
- 清理用 `mcp__aiquant__q_cache_clear`；清理前确认哪些标的仍被策略引用。
- 导出留痕用 `mcp__aiquant__q_export_csv`，导出的 CSV 是报告可复现的凭据。
- 缓存文件不得含任何凭据或 token。

## 6. 数据质量校验清单（逐项打勾，缺一项判"不可用"）

1. **行数与区间**：实际行数与请求交易日数一致；差异>1% 必须解释（停牌/新股/退市）。
2. **缺失值**：`open/high/low/close/volume` 空值率 >0.5% 判不可用。
3. **异常值**：单日涨跌幅超市场限制（A股 ±10%，ST ±5%）逐个核对；`close<=0`、`volume<0` 判脏。
4. **OHLC 自洽**：`low <= open,close <= high` 必须成立。
5. **重复行**：同一交易日多行 → 去重并记录。
6. **前视偏差**：确认所有决策字段在决策时点已知——财报按**公告日**而非报告期对齐，因子只用 t-1 及之前数据，禁止用当日收盘价做当日决策。
7. **复权一致性**：全序列同一复权方式与基准日。
8. **交易日历一致性**：序列日期全部是真实交易日，无周末/节假日混入。

## 7. 交付格式

每份数据集交付时必须同时给出：规范码、数据源与库版本、区间、周期、复权方式与基准日、行数、校验结论（通过/不通过 + 不通过项）。落库用 `aiquant_note`。凭据只从环境变量读，禁止写入缓存、策略或报告。
