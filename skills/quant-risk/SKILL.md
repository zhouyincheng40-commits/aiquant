# 风控

风控的输出永远是**判定**，不是建议。判定只有两种：`通过` 或 `不通过（缺什么）`。

## 1. 仓位与集中度上限（默认值，改动必须写明理由）

| 项目 | 上限 | 口径 |
|---|---|---|
| 总仓位 | ≤ 100% | 现金+持仓 ≤ 总资金，禁止隐性杠杆 |
| 单票上限 | ≤ 10% | 单标的市值 / 总资产 |
| 单行业上限 | ≤ 30% | 按申万一级行业归类 |
| 前 5 大持仓合计 | ≤ 40% | 集中度红线 |
| 单日新增仓位 | ≤ 20% | 防止一次性打满 |
| 单笔风险 | ≤ 总资产 2% | `|入场价 - 止损价| * 股数 / 总资产` |
| 流动性 | 持股数 ≤ 日均成交量的 1% | 用 20 日均量，避免自己砸盘 |

仓位由**风险预算**倒推：`股数 = (总资产 * 单笔风险%) / (入场价 - 止损价)`，而不是先拍股数再补止损。

## 2. 回撤熔断与波动率目标

- 熔断线（以历史高点回撤为准，逐级执行）：
  - `-10%`：暂停新开仓，只允许减仓；
  - `-15%`：仓位降至 50%；
  - `-20%`：全部平仓，人工复核后才可重启。
- 熔断判定用**日频净值**，触发当日收盘后执行，次日开盘减仓（遵循次日成交规则）。
- 波动率目标：年化目标波动 `15%`；实际波动 = 近 60 日日收益标准差 × `sqrt(252)`。
  仓位缩放系数 `= min(1, 目标波动 / 实际波动)`；实际波动 > 2 倍目标时系数强制降到 0.5 以下。
- 熔断线与目标波动必须写进策略 `params.yaml`，代码读取，不许写死。

## 3. VaR / ES 口径（两种都算，给出区间）

- **历史模拟法 VaR95**：取近 250 个交易日日收益的 5% 分位数，`VaR95 = -q05`。
- **参数法 VaR95**：`-(μ - 1.645 * σ)`，μ、σ 用近 60 日。
- **ES95（条件风险价值）**：所有日收益 < `-VaR95` 的样本的均值取绝对值。
- 报告必须写清：置信水平、窗口长度、方法、以及"VaR 是单日还是持有期"。
- 组合 VaR 不得用个股 VaR 简单相加，必须用协方差矩阵计算。

## 4. 相关性矩阵检查

1. 用近 60 日与近 250 日两套窗口分别算持仓两两相关性。
2. 任意一对持仓相关系数 > `0.8` → 视为同一风险敞口，合并计算集中度，并强制减持其中之一。
3. 组合平均相关性 > `0.6` → 判定分散化失效，要求降低总仓位。
4. 相关性在 60 日窗口突然上升（相对 250 日上升 > 0.3）→ 标注"相关性突变"风险。

## 5. 止损止盈与规则模板

```
入场：<信号>，同时确定止损价 stop = 入场价 * (1 - 8%)（或 入场价 - 2*ATR14）
止损：收盘价 <= stop → 次日开盘市价平仓
移动止盈：盈利 > 15% 后，stop 上移到 最高价 * (1 - 10%)，只上移不下移
分批止盈：盈利 20% 减半仓，剩余按移动止盈持有
时间止损：持有 20 个交易日仍未盈利 → 平仓
单标的累计亏损达总资产 2% → 立即平仓，不再加仓
```

规则必须与 `quant-backtest` 一致：回测里没实现的止损规则，不允许写进实盘计划。

## 6. 风控红线（触发任一条 → 拒绝上线）

1. 回测未含手续费/滑点/次日成交/涨跌停不可成交任一项。
2. 无样本外结果，或样本外夏普低于样本内 50%。
3. 最大回撤 > 25%，或回撤未给起止日期。
4. 单票 > 10%、单行业 > 30%、前五大 > 40%。
5. 无止损规则，或止损规则未在回测中生效。
6. 交易次数 < 30 次仍宣称策略有效。
7. 组合平均相关性 > 0.6 或存在相关系数 > 0.8 的持仓未处理。
8. 持仓标的日均成交额 < 5000 万元（流动性不足）。
9. 策略文件或报告中出现账号、密钥、token。
10. 无法用一条命令复现回测结果。

判定输出格式：`风控判定：通过 / 不通过（命中第 N 条：<原文>）`。

## 7. 落库与验收

- 判定结论必须调 `aiquant_risk` 写入看板事实库；当前持仓用 `aiquant_position` 读取核对，两者数字必须一致，不一致先查账再下结论。
- 验收：红线 10 条逐条给出结论（通过/命中/不适用 + 依据数值）；每项指标都指向可复现的命令与数据区间。
