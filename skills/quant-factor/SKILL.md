# 因子研究

因子的唯一验收标准是：**可复现的计算 + 明确的 IC/IR + 明确的失效条件**。只给一个"看起来有效"的曲线不算结论。

## 1. 因子构建（公式固定，不得含糊）

统一记 t 为交易日，`close_t`、`vol_t`、`amount_t`、`turnover_t` 为该日收盘价、成交量、成交额、换手率。

| 类别 | 构造 | 说明 |
|---|---|---|
| 动量 | `close_t / close_{t-N} - 1`，N=20/60/120 | 跳过最近 1 日（`close_{t-1}` 为止）以避开短期反转污染 |
| 反转 | `close_{t-1} / close_{t-N} - 1` 取负，N=5/20 | 短周期反转，注意与动量口径互斥 |
| 波动率 | `std(ret, N) * sqrt(252)`，N=20/60 | 低波动因子取负号后排序 |
| 换手 | `mean(turnover, N)`，N=20 | 需先剔除停牌日与上市未满 N 日的样本 |
| 量比 | `vol_t / mean(vol, N)`，N=5/20 | 与换手相关性高，二者只留一个 |
| 市值 | `close_t * 总股本`，取自然对数 | 中性化时的标准暴露项，勿同时当因子与暴露 |
| 质量 | 净资产收益率、毛利率、资产负债率、经营现金流/净利润 | 必须按**公告日**对齐，见 §2.4 |

## 2. 预处理四步（顺序不可换）

1. **去极值**：对每个截面用中位数绝对偏差法，`|x - median| > 3 * 1.4826 * MAD` 的截断到边界；或按分位数截断（1%/99%）。禁止只用 `3σ`（对厚尾不稳健）。
2. **标准化**：截面 Z-score，`(x - mean) / std`；若分布明显偏斜，先做秩变换再标准化。
3. **中性化**：对行业哑变量与市值对数做截面回归，取残差作为因子值：
   `factor = α + Σ β_i * industry_i + γ * ln(mktcap) + ε`，使用 `ε`。
   行业分类必须与股票池同期一致；缺失行业的新股剔除。
4. **对齐与截断**：财报类字段按公告日可用，t 日截面只能用公告日 ≤ t 的数据。

## 3. IC / IR 与分层回测流程

1. 定股票池（如沪深300/中证500/全A剔除 ST 与上市不足 60 日），定区间（样本内/样本外分开）。
2. 每期算因子值与下期收益的截面相关系数（Pearson 与 Spearman 都算）。
3. 汇总得到 IC 均值、IC 标准差、`IR = IC均值 / IC标准差`、IC 胜率（IC>0 的期数占比）、t 值。
4. 分层：按因子值分 5 或 10 组，算各组下期收益；检查单调性（组序与收益序的秩相关）与多空组合（首组减尾组）净值。
5. 换手与衰减：算因子值的期均换手率，以及 IC 随持有期（1/5/10/20 日）的衰减曲线。

**复现命令（必须写进结论）**：
```
mcp__aiquant__q_factor_ic
```
调用前先 `mcp__aiquant__q_env` 确认参数模式；结果以看板/导出的 CSV 字段为准。核对时**必须逐项确认存在这些字段**：IC 均值、IC 标准差、IR、IC 胜率、分层各组收益、多空净值。字段缺失或名称不同 → 以 `q_factor_ic` 实际返回为准并在结论里写清，禁止按记忆套字段名。选股名单用 `mcp__aiquant__q_screen`，导出用 `mcp__aiquant__q_export_csv`。

## 4. 因子失效判定（满足任一即判失效）

1. `|IR| < 0.3`；
2. IC 胜率 < 55%；
3. 分层收益非单调（末组收益高于首组，或中间组严重错序）；
4. 样本外 IC 均值低于样本内的 50%（过拟合信号）；
5. 多空组合扣成本后年化 ≤ 0（成本口径见 `quant-backtest`）；
6. 因子与已知因子截面相关性 > 0.7（增量信息不足，需先做正交化）。

结论必须写成"通过/不通过 + 命中哪条 + 样本内/样本外数值"。

## 5. 复现要求

任何因子结论必须同时给出：因子公式、参数 N、股票池、区间、预处理参数（截断阈值、中性化暴露项）、`q_factor_ic` 的完整参数、IC/IR 数值、失效判定结果。落库用 `aiquant_note`；因子代码落 `D:\量化\strategies\<name>\`（见 `quant-strategy`）。禁止只看样本内、禁止只报 IC 不报 IR 与分层。
