# 策略研发

策略 = 可执行的信号规则 + 明确的仓位规则 + 明确的风控规则。三者缺一不可，缺了就不叫策略，只叫指标。

## 1. 选型表（先按此表定类型，再动手写代码）

| 类型 | 适用场景 | 典型信号 | 不适合 |
|---|---|---|---|
| 趋势 | 单边行情、日线以上周期 | 双均线金叉（快 N 上穿慢 M）、唐奇安通道突破 | 震荡市（反复止损） |
| 动量 | 横截面选股、周/月频调仓 | 过去 N 日收益排序取前 K 名 | 样本股少、高换手成本敏感 |
| 均值回归 | 震荡市、分钟级 | 偏离均线超 k 倍标准差反向开仓 | 单边趋势（持续扛单） |
| 多因子 | 中低频选股 | 多因子打分加权排序 | 因子未通过 IC 检验时 |
| 事件驱动 | 财报、分红、指数调仓 | 事件日 ±N 日窗口内开仓 | 事件样本不足 30 次时 |

选型硬规则：**没有做过 IC/IR 检验就不许上多因子**（见 `quant-factor`）；趋势与均值回归必须先判定当前市场状态（用 60 日区间效率或均线离散度）。

## 2. 信号定义模板（每个信号必须填满六项）

```
信号名：
方向：做多 / 做空 / 平仓
触发条件：<用可计算表达式，如 close > MA(close,20) 且 MA20 > MA60>
数据频率：日线 / 5分钟
执行时点：次日开盘（默认，必须次日成交）
仓位规则：<目标仓位%，或按 ATR / 波动率缩放>
失效条件：<何种情况下信号作废，如连续 3 日反向>
```

禁止出现"逢低买入""趋势走强"这类无法计算的描述。凡是写不出表达式的条件，一律不写进策略。

## 3. 参数化约定

- 策略描述文件统一 YAML，放 `D:\量化\strategies\<name>\params.yaml`。
- 参数只放**可调数值与标的池**，禁止放凭据、账号、路径以外的东西。
- 参数区间必须写成可扫的离散列表，供 `mcp__aiquant__q_optimize_grid` 网格搜索：

```yaml
name: ma_cross
symbols: [SH600519, SZ000001]
freq: 1d
start: "2020-01-01"
end: "2025-12-31"
params:
  fast: [5, 10, 20]
  slow: [30, 60, 120]
cost:
  commission_bps: 2.5
  slippage_bps: 5
  fill: next_open
```

- 参数命名固定：`fast`/`slow`/`lookback`/`topk`/`rebalance`。同一含义不换名。
- 改参数必须同时改 README 里的最优参数与依据，不允许代码与文档不一致。

## 4. 落盘规范（缺一个文件即视为未完成）

```
D:\量化\strategies\<name>\
  strategy.py     # 唯一入口，可独立运行
  params.yaml     # 参数与标的池
  README.md       # 见下
```

`strategy.py` 硬要求：
1. 顶部 `if __name__ == "__main__":` 可直接跑出一次完整回测；不在 import 期做重活。
2. 只用 `open/high/low/close/volume` 与已落盘数据，不联网取数（数据来自 `D:\量化\data\cache`）。
3. 信号函数与回测循环分离：`def signal(df, params) -> pd.Series`，返回 -1/0/1 或目标仓位。
4. 所有移位用显式 `shift(1)`，禁止用当日收盘价成交。
5. 参数从 `params.yaml` 读，不写死在代码里。
6. 运行环境固定：`C:\Users\33096\.conda\envs\aiquant\python.exe strategy.py`。

`README.md` 必须包含：策略类型与适用场景、信号六项模板的填写结果、参数列表与含义、默认参数、依赖环境与运行命令、以及一句"本策略已通过/未通过 `quant-backtest` 验证"。

## 5. 验收标准

1. `python strategy.py` 能跑通并输出指标（见 `quant-backtest` 的口径）。
2. `params.yaml` 与代码中读取的键完全一致（多键/少键都算失败）。
3. 信号可复现：同一区间同一参数跑两次结果完全一致（无随机数，或已固定种子）。
4. 已跑样本外：策略在样本外区间也有结果，不允许只交样本内。
5. 代码中不存在任何账号、密钥、token；`grep -i "token\|password\|secret\|key" strategy.py` 无命中。
6. 回测结果已用 `aiquant_backtest` 落库。

## 6. 交付

给用户的回复必须含：策略路径、运行命令、参数、样本内/样本外指标、成本假设、以及限制条件。结论交给 `quant-backtest` 与 `quant-risk` 判定是否可用，研发者不自行宣布"可以上实盘"。
