# 投研报告

报告的质量标准只有一条：**每个结论都能被一条命令重跑出来**。做不到的句子删掉，不许保留。

## 1. 落盘与命名

- 路径：`D:\量化\reports\<YYYYMMDD>-<主题>.md`，例如 `D:\量化\reports\20261009-茅台动量因子检验.md`。
- 主题用中文短语，不含空格与特殊字符；日期用报告**生成日**（本地时区 `Asia/Shanghai`）。
- 同一天同一主题二次修订：加后缀 `-v2`，不覆盖上一版。
- 报告完成后用 `aiquant_report` 落库登记（标题、路径、结论摘要），保证 `aiquant_board` 能查到。

## 2. 报告模板（章节顺序固定，不可增删）

```markdown
# <主题>

## 1. 结论先行
- 结论一：<一句话，含具体数值与样本区间>
- 结论二：...
- 结论级别：<已用真实数据验证 / 仅样本内 / 待验证>

## 2. 数据与口径
| 项目 | 内容 |
|---|---|
| 标的（规范码） | SH600519 |
| 区间 | 2020-01-01 ~ 2025-12-31 |
| 数据源与版本 | 见 quant-data 通道表 |
| 周期 / 复权 | 日线 / 前复权，基准日 2026-10-09 |
| 股票池 | 全A 剔除 ST 与上市不足 60 日 |
| 成本假设 | 手续费 2.5bps + 印花税 5bps + 滑点 5bps + 次日开盘成交 |
| 数据质量 | 通过（行数 N，缺失率 0%） |

## 3. 图表
（净值曲线/分层收益/IC 序列，每个图下方注明生成它的命令）

## 4. 风险与反例
- 反例：<找出与结论相反的样本，如某段区间结论不成立>
- 风险清单：<过拟合红旗命中项、流动性、相关性、容量>

## 5. 可复现命令
（逐条列出，含完整参数）

## 6. 未验证项与假设
（明确写出没做到、没数据支撑的部分）
```

## 3. 结论写法要求

1. 每个结论三件套齐全：**数值 + 区间 + 口径**。例：`2020-01-01 至 2025-12-31，日线前复权，20 日动量因子 IC 均值 0.031、IR 0.42`。
2. 样本内与样本外分开写，不合并成一个数字。
3. 结论级别必须自报：`仅样本内`、`已含样本外`、`已含 walk-forward`。升级级别只能靠新增验证，不能靠措辞。
4. 禁止的说法：`预计收益 X%`、`目标价 X`、`胜率可达 X%`、`稳赚`、`无风险`。
   允许的说法：`在 <成本与撮合假设> 下，历史回测年化 X%，样本外 Y%，最大回撤 Z%（起止日期）`。
5. 任何"较好/不错/显著"这类形容词，后面必须紧跟具体数字。

## 4. 可复现命令要求

每条命令必须能原样复制执行，包含：完整工具名、全部参数、标的、区间。至少覆盖：

```
aiquant_env                                   # 环境自检
mcp__aiquant__q_env                           # MCP 通道自检
mcp__aiquant__q_klines                        # 原始行情
mcp__aiquant__q_indicators                    # 指标
mcp__aiquant__q_factor_ic                     # 因子 IC/IR/分层
mcp__aiquant__q_backtest_ma                   # 基线回测
mcp__aiquant__q_optimize_grid                 # 参数寻优
mcp__aiquant__q_screen                        # 选股
mcp__aiquant__q_export_csv                    # 导出留痕
aiquant_backtest / aiquant_risk / aiquant_board   # 落库与读取
```

引用数据文件时写完整路径（如 `D:\量化\data\cache\SH600519\1d_qfq_20200101_20251231.csv`）与导出命令。工具调用参数以实际返回为准；查询字段前先看真实输出，禁止按记忆写字段名。

## 5. 交付前自检（逐项打勾）

1. 每个结论都能指向 §5 里的一条命令。
2. 所有数字都能在工具输出或导出 CSV 中找到出处。
3. 样本内/样本外划分点写明，成本假设写明。
4. 反例章节非空（找不到反例要写"未找到反例，已检查 X 个维度"，并列出检查维度）。
5. 未验证项与假设章节非空。
6. 报告中不含账号、密钥、token（`grep -ri "password\|token\|secret" 报告文件` 无命中）。
7. 文件已落 `D:\量化\reports\`，并用 `aiquant_report` 登记。

任一不满足 → 报告判为未完成。
