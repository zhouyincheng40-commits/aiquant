# 回测与验证

回测的唯一用途是**证伪**。任何缺成本、缺样本外、缺红旗检查的回测结论一律判无效，不得进入 `quant-risk` 与实盘流程。

## 1. 撮合与成本（四项全部必填，缺一项结论无效）

| 约束 | 取值 | 实现要求 |
|---|---|---|
| 手续费 | 默认双边 `commission_bps: 2.5`（万2.5），卖出另加印花税 `stamp_bps: 5` | 按成交额计提，买卖分开 |
| 滑点 | 默认 `slippage_bps: 5`（万5） | 买入价 `= 价 * (1 + s)`，卖出价 `= 价 * (1 - s)`；小市值/低流动性标的提高到 10–20 |
| 次日成交 | 信号在 t 日收盘生成，`t+1` 开盘成交 | 代码必须显式 `position = signal.shift(1)`；禁止 `close_t` 成交 |
| 涨跌停不可成交 | 开盘价触及涨停不许买入，触及跌停不许卖出；停牌不许成交 | 用前一交易日收盘价与板块限制（主板 ±10%、创业板/科创板 ±20%、ST ±5%）判断 |

附加硬规则：
1. 停牌期间持仓保留、不计成交（见 `quant-data`）。
2. 新股上市首日与上市不足 60 日的不进池。
3. 资金不足时按可用资金部分成交并记录，不许假设无限资金。
4. 成本假设必须写进结论原文，不许只写"已考虑成本"。

## 2. 样本划分与 walk-forward

1. **样本内**：前 60%–70% 区间，用于定参数。
2. **样本外**：剩余 30%–40%，参数固定不再调整，只跑一次。样本外不许回看调参——调了就不再是样本外。
3. **walk-forward**：把全区间切成 K 段（K≥4），每段"前段定参、后段验证"，滚动前进，汇总各验证段结果。定参段与验证段不得重叠。
4. 三段结论都要给：样本内、样本外、walk-forward 汇总。只给样本内的直接判无效。

**工具**：基线回测用 `mcp__aiquant__q_backtest_ma`；参数搜索用 `mcp__aiquant__q_optimize_grid`（参数区间来自策略 `params.yaml`）。调用前先 `mcp__aiquant__q_env` 确认当前可用参数模式，以实际返回字段为准。

## 3. 过拟合红旗清单（命中任一必须写进结论并降级）

1. 参数网格里"最优"点紧邻的参数表现崩坏（尖峰型最优，不是平台型）。
2. 参数越多越好，加参数就涨收益，但样本外同步下跌。
3. 换手率过高（年化换手 > 3000%）且扣成本后收益转负。
4. 收益集中在个别交易日或个别标的：剔除最好的 5 个交易日/2 个标的后年化转负。
5. 样本外夏普 < 样本内夏普的 50%。
6. 交易次数 < 30 次（统计不可信）。
7. 同一策略在不同股票池（沪深300 与中证500）结论相反。
8. 只优化了收益未优化回撤，最大回撤随参数单调恶化。

结论格式：`过拟合判定：通过 / 命中 N 条（列出条目）`。

## 4. 必须输出的指标口径（每个都要给定义，不许只报数）

| 指标 | 口径 |
|---|---|
| 年化收益 | `(期末净值/期初净值)^(252/交易日数) - 1` |
| 最大回撤 | 净值序列峰谷最大跌幅，给出起止日期 |
| 夏普 | `(年化收益 - 无风险利率) / (日收益std * sqrt(252))`，无风险利率默认 2% |
| 卡玛 | 年化收益 / 最大回撤绝对值 |
| 胜率 | 盈利交易笔数 / 总交易笔数 |
| 盈亏比 | 平均盈利 / 平均亏损（绝对值） |
| 换手 | 年化换手率 = 年度买卖成交额 / 平均持仓市值 |
| 交易次数 | 总笔数，<30 必须标注不可信 |

另外必须附：净值曲线区间、成本假设、样本内/样本外拆分点。

## 5. 落库与验收

跑完**必须**调 `aiquant_backtest` 把结果写入看板事实库，字段至少覆盖 §4 全部指标 + 成本假设 + 样本划分。未落库视为未完成。

验收清单：
1. 四项撮合成本约束全部生效（能给出对应参数日志）。
2. 样本内、样本外、walk-forward 三段结果齐全。
3. 过拟合红旗已逐条判定。
4. 指标口径与上表一致，且每个数字都能由 `strategy.py` + `params.yaml` 重跑得到。
5. `aiquant_backtest` 已落库，`aiquant_board` 能查到。

只调 `q_backtest_ma` 不落库、或只给一张净值曲线而不给指标的，一律打回。
